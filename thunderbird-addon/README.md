# 업무 대시보드로 보내기 (Thunderbird 애드온)

Thunderbird에서 메일을 고르고 **대시보드로 보내기**를 한 번 누르면, 메일(본문·첨부)이 Apps Script를 통해 구글 드라이브 `업무 대시보드/inbox`에 저장되고, 대시보드의 이메일 처리 목록에 쌓입니다.

## 설치
1. `send-to-dept-dashboard.xpi`를 받습니다.
2. Thunderbird → 도구(☰) → **부가 기능 및 테마** → 톱니바퀴 → **파일에서 부가 기능 설치** → xpi 선택 → 추가.
3. 설정 창이 열리면 대시보드(PC) 설정 → 저장·구글 → **연결 링크 복사**로 복사한 링크를 붙여넣고 **저장하고 연결 확인**.

## 쓰기
- 메일을 열었을 때 메일 위의 **대시보드로 보내기** 버튼
- 메일 목록에서 우클릭 → **대시보드로 보내기** (여러 통 선택 가능)
- 도구 모음의 **대시보드로 보내기** 버튼

첨부는 합계 20MB까지 내용까지 보내고, 넘는 파일은 이름만 보냅니다. 같은 메일을 두 번 보내면 한 번만 처리합니다.

## 만들기
`zip -r -FS ../send-to-dept-dashboard.xpi manifest.json background.js options.html options.js icons`

## 보낸 기록 (1.1)
보낸 메일은 애드온 설정 화면 아래 **대시보드로 보낸 기록**에 남습니다(최근 300건): 보낸 시각, 결과(보냄·이미 보낸 메일·실패와 이유), 제목·보낸 사람·폴더, 첨부 수와 크기. 제목·보낸 사람으로 찾기, 결과별 보기, CSV로 저장, 기록 지우기를 할 수 있습니다. 메일 목록 우클릭 → **대시보드로 보낸 기록 보기**로 바로 열 수 있습니다. 기록은 이 Thunderbird 안에만 저장됩니다.

## Thunderbird로 답장 (1.2)
대시보드 메일 화면의 **Thunderbird로 답장**(목록에서는 "보내기")을 누르면, 몇 초 안에 Thunderbird가 그 메일의 **답장 창**을 엽니다. Thunderbird에서 직접 답장을 누른 것과 같아서 원본 메일이 아래에 인용되고, 보내는 사람·숨은 참조 설정도 그대로이며, 맨 위에 대시보드의 답장 초안이 들어갑니다. 내용을 확인하고 **보내기**만 누르면 됩니다. (Apps Script 버전 12 필요, Thunderbird가 켜져 있어야 합니다. 15분 안에 열리지 않으면 요청은 사라집니다.)

## 1.3
- Thunderbird 안에서 바로: 메일 목록에서 우클릭 → **대시보드 답장 초안으로 답장**. 원본이 인용된 답장 창에 대시보드의 초안이 들어갑니다.
- 원본 찾기를 더 튼튼하게(새 Thunderbird의 나눠 받는 검색 결과, 보낸 사람 최근 메일에서 찾기).
- 설정 화면에 애드온 버전과 "대시보드 답장 요청 확인" 상태(마지막 확인 시각·오류)를 보여 줍니다.
