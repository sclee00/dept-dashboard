# 학과장실 대시보드로 보내기 (Thunderbird 애드온)

Thunderbird에서 메일을 고르고 **대시보드로 보내기**를 한 번 누르면, 메일(본문·첨부)이 Apps Script를 통해 구글 드라이브 `학과장실 대시보드/inbox`에 저장되고, 대시보드의 이메일 처리 목록에 쌓입니다.

## 설치
1. `send-to-dept-dashboard.xpi`를 받습니다.
2. Thunderbird → 도구(☰) → **부가 기능 및 테마** → 톱니바퀴 → **파일에서 부가 기능 설치** → xpi 선택 → 추가.
3. 설정 창이 열리면 대시보드(PC) 설정 → 저장·구글 → **연결 링크 복사**로 복사한 링크를 붙여넣고 **저장하고 연결 확인**.

## 쓰기
- 메일을 열었을 때 메일 위의 **대시보드로 보내기** 버튼
- 메일 목록에서 우클릭 → **대시보드로 보내기** (여러 통 선택 가능)
- 도구 모음의 **대시보드로 보내기** 버튼

첨부는 합계 20MB까지 내용까지 보내고, 넘는 파일은 이름만 보냅니다. 같은 메일을 두 번 보내면 한 번만 처리합니다.

## 만들기
`zip -r -FS ../send-to-dept-dashboard.xpi manifest.json background.js options.html options.js icons`

## 보낸 기록 (1.1)
보낸 메일은 애드온 설정 화면 아래 **대시보드로 보낸 기록**에 남습니다(최근 300건): 보낸 시각, 결과(보냄·이미 보낸 메일·실패와 이유), 제목·보낸 사람·폴더, 첨부 수와 크기. 제목·보낸 사람으로 찾기, 결과별 보기, CSV로 저장, 기록 지우기를 할 수 있습니다. 메일 목록 우클릭 → **대시보드로 보낸 기록 보기**로 바로 열 수 있습니다. 기록은 이 Thunderbird 안에만 저장됩니다.
