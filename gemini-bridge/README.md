# 학과장실 대시보드 · Gemini 연결 (크롬 확장)

대시보드가 AI에게 물을 때, 이 확장이 작은 Gemini 창(gemini.google.com)에 질문을 넣고 답을 읽어 대시보드로 돌려줍니다. 복사·붙여넣기가 없습니다.

설치: `gemini-bridge.zip` 압축 풀기 → 크롬 `chrome://extensions` → 개발자 모드 켜기 → "압축해제된 확장 프로그램 로드" → 푼 `gemini-bridge` 폴더 선택 → 대시보드 새로고침.
크롬에서 gemini.google.com에 로그인되어 있어야 합니다. 질문할 때마다 새 대화를 엽니다.

주의: 웹 화면을 프로그램으로 조작하는 것은 Google 약관에 어긋날 수 있습니다(사용자 판단). Gemini 화면 구조가 바뀌면 동작하지 않을 수 있고, 그때 대시보드는 복사 방식으로 넘어갑니다.
