# 학과장실 대시보드

컴퓨터공학과 학과장실 업무 달력입니다. 일정, 마감, 답장 기한, 불가 시간, 구글 캘린더 일정을 한 달력에 아이콘으로 보여 주고, 붙여넣은 메일을 AI로 분석해 일정·할 일·답장 초안·조교 지시 메일을 만듭니다.

- 주소: https://sclee00.github.io/dept-dashboard/
- 저장: PC의 구글 드라이브 폴더(Google Drive 데스크톱 앱)에서 고른 폴더의 `dashboard-data.json`. 하루 한 번 `backup/`에 사본. 폴더를 고르기 전에는 그 브라우저에만 저장 (크롬·엣지 필요)
- AI 분석: 설정 → 기본 → AI 분석에서 'Gemini 자동'(Apps Script 버전 10 + Gemini API 키, 키는 스크립트 속성에만 보관) 또는 복사·붙여넣기 방식(Gemini·ChatGPT·Claude 창)
- 캘린더: 일정 옆 "구글에 추가"는 구글 캘린더 일정 만들기 화면을 채워서 엽니다(설정 필요 없음). 구글 일정을 이 달력에 띄우는 것은 선택 기능이며 OAuth 클라이언트 ID가 필요합니다

## 처음 설정

1. 각 PC에 Google Drive 데스크톱 앱을 설치하고, 내 드라이브에 `학과장실 대시보드` 폴더를 만듭니다.
2. 대시보드 위쪽 "저장 폴더 고르기"를 눌러 그 폴더를 고릅니다. 크롬이 물으면 "모든 방문에 허용"을 고르세요.

## 구글 캘린더 읽기·쓰기 (Apps Script, 추천)

1. script.google.com → 새 프로젝트 → `apps-script/Code.gs` 내용을 붙여넣고 `KEY`를 긴 비밀 문자열로 바꿉니다.
2. 함수 `authorize`를 한 번 실행해 권한을 허용합니다.
3. 배포 → 새 배포 → 웹 앱 (실행 사용자: 나, 액세스: 모든 사용자) → 웹 앱 URL 복사.
4. 대시보드 설정 → 구글 캘린더 → 웹 앱 주소와 비밀 키 입력 → 연결 확인 → 저장 → 가져올 캘린더 체크.

## 다른 방법: OAuth 클라이언트 ID (고급)

1. Google Cloud Console에서 프로젝트를 만들고 **Google Calendar API**를 사용 설정합니다.
2. OAuth 동의 화면을 **외부 / 테스트**로 두고, 테스트 사용자에 본인 Gmail을 추가합니다.
3. 사용자 인증 정보 → OAuth 클라이언트 ID → **웹 애플리케이션**을 만들고, 승인된 JavaScript 원본에 `https://sclee00.github.io`를 넣습니다.
4. 받은 클라이언트 ID를 `config.js`의 `googleClientId`에 넣습니다. 대시보드 설정 창에 직접 넣어도 됩니다(그 브라우저에만 저장).

## 데이터와 보안

- 이 저장소에는 코드만 있습니다. 메일과 일정 데이터는 저장소에 올라가지 않습니다.
- 이 페이지는 사용자가 고른 폴더 하나만 읽고 씁니다.
- 설정 창의 **파일로 내보내기 / 파일에서 가져오기**로 백업하거나 옮길 수 있습니다.

## Thunderbird에서 보내기

`thunderbird-addon/` 폴더의 애드온(`send-to-dept-dashboard.xpi`)을 설치하면 메일에서 **대시보드로 보내기**를 눌러 대시보드로 바로 넘길 수 있습니다. 메일은 Apps Script(버전 8 이상)를 통해 드라이브 `학과장실 대시보드/inbox`에 저장되고, 대시보드가 이를 가져와 이메일 처리 목록에 "분석 전"으로 쌓고(첨부 내용도 읽어 둠), 목록의 "분석"을 누르면 분석합니다. 처리한 메일은 `inbox/done`으로 옮겨집니다.

한글(.hwp) 첨부는 대시보드가 직접 글자를 읽습니다(암호·배포용 문서 제외). .doc·.ppt·.rtf·.odt 등은 Apps Script(버전 9, 서비스에 Drive API 추가)가 구글 드라이브로 PDF로 바꿔 함께 넣습니다.

## 아이폰 메일 등에서 보내기

아무 메일 앱에서나 메일을 `내아이디+dash@gmail.com`(Apps Script 계정 주소에 +dash)로 **전달**하면, Apps Script(버전 11, 지메일 권한·5분 트리거)가 받아 드라이브 inbox에 넣고 대시보드 이메일 처리 목록에 들어옵니다. 처리한 메일에는 지메일 라벨 `대시보드/처리됨`이 붙습니다.
